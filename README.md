# 🦈 Pating Backup Manager 🦈
## A simple file and folder backup manager for Linux and Windows, designed to make scheduled backups easy to configure and manage.

### Features
- Full backups: Create complete backups of selected files and folders.
- Automatic scheduling: Configure the starting time and the interval between backups.
- Cross-platform: Designed to work on Linux and Windows.
- Multilingual interface: Available in four languages (English, Spanish, Portuguese and Galician)
- Backup management: Dedicated management screen to view and manage backups.
- User-friendly interface: Manage your backup configuration through the application.
